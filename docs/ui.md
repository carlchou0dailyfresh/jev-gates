# 本機可視化工作台

工作台介面使用繁體中文。前端獨立置於 `ui/`，核心函式庫的使用者不需安裝 React 或 Vite。所有真值、執行預算、DAG 驗證、完整性驗證與離線重算均透過本機服務使用同一核心；前端只負責呈現、編輯草稿與圖形布局。

## 啟動與建置

從 repo 根目錄執行 README 的工作台啟動指令。本機服務預設為 `http://127.0.0.1:4317`，正式介面檔案由 `ui/dist` 提供。

```sh
npm --prefix ui ci
npm --prefix ui run build
```

開發時可以先啟動本機 API，再另開終端執行：

```sh
npm --prefix ui run dev
```

Vite 只監聽 `127.0.0.1:4318`，`/api` 代理至 `127.0.0.1:4317`。模型金鑰不進入前端設定。

## 操作導覽

1. 在「電路工作台」選情境 A–D 與正常、缺失、衝突、故障等路徑。固定種子可重現世界案例。預設 `Fixture` 使用離線腳本回應，不代表模型品質。
2. 研究案例可調整任務、上下文長度與合成成本限制；探測站可調整能源、時間與儀器。按「套用限制／重新產生」後再執行，精確欄位由核心重算。改了控制項卻未套用時不能執行。
3. 按「執行電路」後，時間軸輪詢核心的真實事件，沒有模擬推理進度。可取消正在進行的工作；取消不表示目的端已撤銷。
4. 點選圖形或排序節點清單，查看問題、原文、判定政策、真值、原因、provider、實際模型與上游影響。UNKNOWN 另顯示需要補充的資料。原始 Noul／Choice／Score 分別原樣呈現。
5. 「增加節點」「編輯節點」「編輯電路」開啟 JSON 契約編輯器。圖形可拖曳、縮放、自動布局、折疊群組；鍵盤連線工具提供等價的建立與移除操作。循環和失去必要輸入的修改由核心拒絕。
6. 每次修改或重跑已保存紀錄都要填原因，並建立 child run；模型原始回應不會被覆寫。離線 fixture 任意修改問題／來源／輸入時，核心不會冒充重新推論；語意節點會棄答。人工判定應明確新增固定值節點並記錄原因。
7. 在執行結果按「匯出」「驗證完整性」「離線重播」。離線重播先重新驗證核心結果，再提供前進、後退與播放。工具只展示既存事件與回執，不重新呼叫；後退不撤銷外部動作。
8. 「證據與主張」查看原文、定位、時間、版本、適用範圍及每個主張的已保存判斷。「分支比較」並排比較兩次執行的節點、輸入、證據、輸出、棄答、延遲與費用。兩份 run 不構成品質提升的統計證明。
9. 「執行庫」可搜尋、匯入、開啟及匯出 run。匯入只接受 JSON 資料；檔案上限為 8 MiB，核心驗證 schema／完整性／重播一致性。損壞檔案顯示持續可讀錯誤。
10. 事故案例可執行沙箱修復與故障注入；pending 動作按「查詢 pending／復原」建立查詢紀錄，不重送修復。模型判斷、工具回執與健康驗證分開呈現。

## 可及性與響應式

- 原生按鈕、表單、標籤、details 及 dialog；可見焦點、跳至主內容連結、錯誤公告與無顏色依賴的 TRUE／FALSE／UNKNOWN 標示。
- 原生模態 dialog 管理焦點陷阱；Escape 與關閉按鈕關閉後回到觸發控制項。
- 768 px 以下移除大型畫布，使用排序節點清單；1050 px 以下以分頁檢視器對話框顯示節點資料。
- 所有按鈕與主要表單控制項至少 44 px。動作區避免 hover 唯一入口。
- 遵守 `prefers-reduced-motion`；圖形不播放推理動畫。離線播放計時器只移動已保存事件的閱讀位置。
- 圖形群組折疊僅影響呈現，不改變核心電路或計算群組真值。已掛載電路以核心 `prefix.node` 命名空間分組；一般案例按節點類型分組，標示「視覺群組」，不宣稱已建立可重用子電路。
- 執行狀態另列「已評估／失敗／逾時／跳過／取消／預算停止／尚未執行」。`provider_started.detail.questionIds` 對應的節點在完成／失敗事件到來前標示 RUNNING；沒有假推理計時器。UNKNOWN 可出現在多種執行狀態中。

## 效能觀察

頁尾提供 20／100／256 節點載入工具，記錄從 API 要求到兩次畫面更新的耗時、user agent 與視窗大小。此數字含網路與呈現，不是純引擎 benchmark，也不能代表所有裝置。核心驗證維持啟用。實際瀏覽器測量與測試證據由交付報告記錄，不能以建置成功冒充互動驗證。

## 選型與固定版本

2026-09-20 依官方文件與 npm registry 確認並固定：

| 項目 | 版本 | 理由 |
| --- | --- | --- |
| React／ReactDOM | 19.3.0 | 前端狀態與可重用互動元件 |
| `@xyflow/react` | 12.11.6 | DAG 圖形、節點選擇、拖曳與縮放；另提供完整清單操作 |
| Vite | 8.3.0 | 獨立開發伺服器與靜態建置 |
| `@vitejs/plugin-react` | 6.1.1 | React 建置支援 |
| TypeScript | 5.9.3 | 與核心共享型別，前端型別檢查 |

官方參考：[React reference](https://react.dev/reference/react)、[React Flow quick start](https://reactflow.dev/learn)、[Vite guide](https://vite.dev/guide/)。依賴確切版本與完整性保存於 `ui/package-lock.json`。

UI 技能使用 `ui-skills-root` 路由至 `ibelick/fixing-accessibility`。前端沒有加入額外的狀態庫、動畫庫或樣式框架。

瀏覽器 E2E 使用獨立開發依賴 Playwright 1.63.0，執行 `npm --prefix ui run test:browser`；此腳本驗證實際操作與呈現，測試結果以產生的報告為準。
