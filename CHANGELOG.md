# Changelog

## 0.1.0 — 2026-09-19

Initial public release:

- Three-valued semantic circuits with Noul, Choice, Score, exact rules, and seven logic operators.
- Explicit context edges for stacked JEV judgments, conditional execution, and reusable namespaced subcircuits.
- Validated TypeSafe, LocalJev, and offline mock providers with bounded calls and auditable traces.
- Stateful controller with verified tool results, persistent checkpoints, and recovery without automatic action replay.
- JSON CLI, Mermaid graph export, runnable examples, bilingual documentation, and offline CI.

The package is experimental. Example thresholds are not calibrated; this release does not establish model accuracy or production tool reliability.
